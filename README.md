# Enterprise RAG — Document Intelligence System

> A professional, lightweight Retrieval-Augmented Generation (RAG) system
> designed for document intelligence on CPU-first machines.

## Overview

This project implements a production-grade RAG pipeline capable of:
- Ingesting PDF and text documents
- Semantic search over document content
- Question answering grounded in your documents
- REST API (FastAPI) + Web interface (Gradio)
